Availability and requirements

Downloads

GlideHorizon is an experimental Android application. This website does not currently distribute the app.

Public release status

No public download currently offered

No APK or Google Play release is available from this website. The intended public app will be free to download and proprietary; no release date is announced here.

Install only an owner-authorized build from the distribution location supplied with that release. A donation is optional and does not purchase access to an app build.

Device requirements

  • Android 8.0 or later, with a working gyroscope and accelerometer for the attitude display.
  • A suitable magnetometer for magnetic heading.
  • A pressure sensor for barometric altitude and flight level.
  • GPS, device location enabled and precise-location permission for GPS indications.
  • Compatible paired Bluetooth Classic SPP devices for Bluetooth transmission, or a trusted local network for another-device Wi-Fi transmission.

A compatible Android version does not guarantee suitable sensors or reliable operation. Read the operational limitations before installing or using the app.

Installing an authorized build

Follow the instructions and license terms supplied with your build. If installing an APK directly, Android may require permission for the browser or file manager to install apps from that source. Grant this only for a trusted source and disable it afterward if no longer needed. Developer mode and USB debugging are not required.

Updates may use different signing keys. Do not uninstall as a first troubleshooting step. Uninstalling or clearing app storage erases private settings, calibration and recordings. Export important recordings first; this does not back up all settings.

After installation, follow getting started and complete ground calibration before configuring the optional XCSoar feed.
